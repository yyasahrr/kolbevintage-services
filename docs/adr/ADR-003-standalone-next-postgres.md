# ADR-003: استک مستقل Next.js و PostgreSQL

## وضعیت

پذیرفته‌شده — ۳ سپتامبر ۲۰۲۶

## تصمیم

کل پلتفرم از یک برنامه Next.js اجرا می‌شود. Route Handlerهای `/store/kolbe/*` و
`/admin/kolbe/*` منطق دامنه، احراز هویت و دسترسی داده را اجرا می‌کنند و مستقیماً به
PostgreSQL متصل هستند.

## پیامدها

- فقط دو پردازه لازم است: PostgreSQL و Next.js.
- API مرورگر same-origin است و به proxy یا publishable key نیاز ندارد.
- فروشگاه، پنل مدیریت، VIP و تأمین‌کننده قرارداد API فعلی خود را حفظ می‌کنند.
- اسکیمای مستقل و seed حساب‌های توسعه در اولین درخواست API به‌صورت idempotent ساخته می‌شود.
