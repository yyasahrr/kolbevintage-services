## خلاصه پیاده‌سازی این نسخه

1. **`npm run dev` حالا هر دو اپ را موازی اجرا می‌کند** (کلبه ۵۱۷۳ + ساپلایر ۵۱۷۴)
2. **صفحه عملکرد (Analytics)**: بازه دلخواه + همه شاخص‌ها + قیف فروش (37-d, 38-d, 39-d)
3. **امتیاز عملکرد**: کارت چندشاخصه با جزئیات و راهکار بهبود (40-d, 41-d)
4. **تنظیمات**: فرم ثبت روزهای تعطیل (30-b)
5. **مالی**: ریز کامل کسورات (33-d)
6. **کاتالوگ**: ورود CSV برای موجودی (7-d)
