# رودمپ حداقلی پلتفرم کلبه

> این سند جایگزین پرسشنامههای `docs/` نیست؛ خروجی فشرده تصمیمهای گرفتهشده برای دو سهگانه «اکنون / مهاجرت / رشد» است. پرسشنامهها بهعنوان چکلیست کشف نیازمندی باقی میمانند و پاسخهای تکمیلشده به همین سند ارجاع داده میشوند.
>
> **مستند مرجع مهاجرت (۲۰۲۶-۰۹-۱۷):** [`architecture-audit-and-migration-blueprint.md`](./architecture-audit-and-migration-blueprint.md) — ممیزی کامل معماری فعلی، طبقهبندی ویژگیها، نقشه‌های localStorage/داده و فازهای استangler را جایگزین فرضهای این سند کنید. موارد P0 کشف‌شده: چکاوت خرده‌فروشی (خطای ۵۰۰)، خودتأییدی عضویت VIP، قیمت‌های کلاینت‌محور.

## اهداف سنجشپذیر (۱۲ ماه)

1. نگهداری بک‌اند یکپارچه Next.js و PostgreSQL بدون موتور تجارت ثالث
2. چکاوت واقعی خردهفروشی: سفارش ثبتشده در دیتابیس + پرداخت درگاهی + موجودی واقعی
3. کاتالوگ دیتامحور (خروج از فایل هاردکد `src/data/catalog.ts` و ادیتور localStorage)
4. آمادگی بار ۱۰۰ هزار کاربر: LCP < ۲.۵ ثانیه، جستجوی سمت سرور، پایش دسترسپذیری

## اکنون (فاز ۰ — همین شاخه)

- [x] رفع خطاهای بلعیدهشده پنل ساپلایر (بنر خطا + تلاش دوباره) — ممیزی P2
- [x] پینکردن وابستگیهای `latest` پنل ساپلایر — ممیزی P2
- [x] میزبانی محلی فونت وزیرمتن (حذف وابستگی به Google Fonts)
- [x] **فاز ۰ ایمن‌سازی (۲۰۲۶-۰۹-۱۷):** رفع خطای ۵۰۰ چکاوت خرده؛ محاسبهٔ سمت سرور قیمت/ارسال/مبلغ کل سفارش خرده با فهرط قیمت `retail_product`؛ اجباری‌شدن تأیید مدیر کل برای عضویت VIP؛ کوک نشستی HttpOnly در کنار توکن + لاگ‌اوت؛ ردِ ورودی نامعتبر (تعداد/محصول ناموجود) با ۴۲۲؛ `Idempotency-Key` روی ثبت سفارش خرده و عمده؛ بستن CORS روی متدهای نوشتنی در پروداکشن؛ الزام `KOLBE_SESSION_SECRET` در بوت استارت پروداکشن؛ ۲۷ تست یکپارچه‌سازی Vitest + workflow سی‌آی (typecheck/test/build)
